# 左视角小孔洞补全设计

## 目标

减少经典立体匹配左视角深度视频中的零散黑点，同时不把大块失配区域伪造成可信深度。

## 行为

- 新增可选的左视角后处理，默认关闭。
- 只处理不接触图像边界且面积不超过 `--left-hole-fill-max-area` 的无效连通域。
- 对每个候选孔洞，从一像素有效边界中选择与孔洞 RGB 灰度均值差不超过 `--left-hole-fill-color-tol` 的像素，并以其深度中位数填充。
- 边界样本不足或 RGB 不一致时保留黑洞。
- 仅在 `--output-view left` 下生效；不改动中心视角融合、WAFT 或其他模型推理。

## 观测

每次运行记录补全耗时、填充连通域数和填充像素数。该步骤改善外观，不增加立体匹配信息；大面积无效区仍保持黑色。
